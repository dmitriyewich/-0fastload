# !0fastload

`!0fastload` — нативный **ASI**-плагин для **GTA San Andreas 1.0 US**, который применяет fastload-патчи при старте процесса.

Плагин рассчитан на использование:

- в одиночной игре;
- при запуске **SA-MP**.

Он **не** зависит от **SAMPFUNCS** и **не** патчит `samp.dll` напрямую.

## Возможности

- В одиночной игре пропускает заставки до главного меню. В SA:MP ранний переход выполняет штатный клиент.
- Убирает штатные заставку, полосу и загрузочную мелодию первого запуска. Последующие загрузки используют обычный путь игры.
- Убирает белую вспышку при первом показе безрамочного окна GTA.
- При запуске Arizona RP пропускает внутриигровую заставку и полосу загрузки. Отдельное окно до появления GTA показывает сам Arizona Games Launcher.
- В SA-MP убирает плавное проявление стартовой камеры при распознанном сценарии `main.scm`. Пауза подготовки камеры и переход звука сохраняются.
- В SA:MP сохраняет обработку первого запуска при потере фокуса и сворачивании. После первичной загрузки управление фокусом и паузой возвращается игре.
- В одиночной игре ненадолго скрывает главное меню при запуске.
- Только в одиночной игре запоминает принятый игрой слот из главного меню или меню паузы. При следующем запуске проверяет слот один раз и загружает его. При отсутствующем или повреждённом сохранении открывается обычное меню.
- В одиночной игре сразу показывает готовую сцену, если первым входом в мир была загрузка сохранения. Затемнения в повторных загрузках и вступительном ролике новой игры работают штатно.
- Маркер `!0fastload_lastslot.bin` содержит один байт. Плагин атомарно заменяет его в каталоге userfiles, полученном через игровой getter. PortableGTA использует свой каталог после установки перенаправления.

## Совместимость

- игра: **GTA San Andreas 1.0 US**. Плагин проверяет PE и инструкции перед установкой соответствующего набора патчей.
- формат: **ASI**;
- архитектура: **x86 (Win32)**.

## Установка

При публикации релиза GitHub Actions собирает плагин в `Release|Win32` из коммита тега.

1. Соберите `build\Release\!0fastload.asi` из исходников или скачайте и распакуйте `fastload-release-win32` из раздела **Artifacts** успешной сборки тега релиза или ветки `main`. [Сборки в GitHub Actions](https://github.com/dmitriyewich/-0fastload/actions/workflows/build-release-win32.yml)
2. Положите `!0fastload.asi` рядом с `gta_sa.exe` или в папку, которую сканирует ASI-loader.
3. При обновлении с [v1.4](https://github.com/dmitriyewich/-0fastload/releases/tag/v1.4) уберите старый `0fastload.asi` из папок, которые сканирует ASI-loader.

## Сборка

Требования:

- **Visual Studio 2026** (или Build Tools) с **Desktop development with C++**, toolset **v145**;
- **Windows SDK 10.0.26100.0**;
- целевая платформа **Win32**.

Сборка через solution использует платформу `x86`.

```powershell
& 'C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe' '.\!0fastload.sln' /t:Build /p:Configuration=Release /p:Platform=x86
```

Сборка напрямую из проекта использует платформу `Win32`.

```powershell
& 'C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe' '.\!0fastload.vcxproj' /t:Build /p:Configuration=Release /p:Platform=Win32
```

Обе команды создают файл

```text
build\Release\!0fastload.asi
```

## Примечания

- **SA-MP** определяется по наличию `samp.dll`, флагам `-c`, `-d`, `/c`, `/d` или параметрам `-h`, `-p`, `/h`, `/p` с допустимым значением хоста или порта.
- Чтобы сбросить автослот, удалите `!0fastload_lastslot.bin` из каталога userfiles. Чтобы сменить слот, загрузите другое сохранение через меню игры.

### Если антивирус ругается

Некоторые антивирусы могут помечать любые **ASI**-моды как подозрительные. Это нормально для таких файлов. Что можно сделать:

- скачивайте `!0fastload.asi` только из [официального репозитория](https://github.com/dmitriyewich/-0fastload) или из **Releases**;
- добавьте папку с игрой или сам файл `!0fastload.asi` в **исключения** антивируса;
- если файл уже удалили или отправили в карантин — восстановите его и разрешите использование.
